# Praman

Explainable risk screening for crypto and fintech. Every risk score comes with proof.

Praman takes a wallet address and returns a 0-100 risk score, plain-language reason codes, and a fund-flow graph. It never holds or moves funds.

**Status:** early prototype for Bengaluru Tech Summit 2026. Demo data is sample (fixture) data unless labelled "live".

> Praman provides screening signals to support human review. It is not legal advice and is not affiliated with any government body.
